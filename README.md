# 🏨 Maison Soleil - Hotel Booking Confirmation Dashboard

A modern, elegant, and fully responsive Hotel Booking Confirmation UI dashboard designed using HTML5 and CSS3. 

![Project Preview](./preview.jpg)

---

## ✨ Features

- **Sidebar Navigation:** Includes active states, badge counts, and brand typography.
- **Weather Widget:** A custom styled warm-amber weather card with a soft glowing sun graphic.
- **Overlapping Receipt & Host Cards:** Visual floating card layout featuring angled transformations and realistic shadows.
- **Dynamic Info Cards:** Styled cards for Arrival, WiFi credentials (with copy UI), and Breakfast schedules using custom colored badges.
- **Typography & Aesthetics:** Clean hierarchy leveraging Google Fonts (`Playfair Display` & `Inter`).

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and content layout.
- **CSS3:** Custom styles, Flexbox, Grid, transforms, transitions, and gradient visual elements.
